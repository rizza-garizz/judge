# HakimPintar Backend

Backend awal Fase 2 memakai Node.js built-in HTTP agar bisa berjalan tanpa instalasi dependency tambahan.

## Run

```bash
npm run dev
```

Server berjalan di:

```text
http://127.0.0.1:4000
```

## Runtime Data

Data development disimpan di:

```text
backend/data/dev-db.json
```

File runtime ini tidak masuk Git.
